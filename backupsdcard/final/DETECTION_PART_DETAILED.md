# 📋 สรุปการทำงาน Part การตรวจจับ (Detection Part) อย่างละเอียด

## 🔄 Flow การทำงานทั้งหมด

---

## 1️⃣ **ขั้นตอนการเริ่มต้นระบบ**

### อ่าน Coils/Registers:
- **M511** (Coil 511, Unit 1) - เริ่ม/หยุดโปรแกรม
  - `ON` → เริ่มการทำงาน (`program_enabled = True`)
  - `OFF` → หยุดการทำงาน (`program_enabled = False`)

### เขียน Registers:
- **D5500** (Register 5500, Unit 1) - เลือกโหมดการทำงาน
  - `7` = ID 7 (Full Auto Mode) - ตรวจจับและประมวลผลทั้งหมด
  - `5` = ID 5 (Capture Only Mode) - ถ่ายภาพเท่านั้น ไม่ประมวลผล
  - `8` = ID 8 (Manual Mode)

---

## 2️⃣ **ขั้นตอนการถ่ายภาพ (เมื่อ M301 ON)**

### อ่าน Coils:
- **M301** (Coil 301, Unit 1) - สัญญาณถ่ายภาพ
  - เมื่อเปลี่ยนจาก `OFF → ON` → เริ่มถ่ายภาพ

### เงื่อนไขการถ่ายภาพ:
1. ✅ `M511 = ON` (โปรแกรมเปิดใช้งาน)
2. ✅ `M130` ไม่ทำงานอยู่ (`d6006_monitoring = False`)
3. ✅ `M600` พร้อม (`m600_reset_pending = False`) หรือถ่ายแบบเงียบ

### การทำงาน:
```
IF M301 ON:
  IF M600 พร้อม:
    → ถ่ายภาพ USB + Sentech ทันที
    → เริ่มประมวลผล
    → ON M600
  ELSE (M600 ยังไม่ reset):
    → ถ่ายภาพและประมวลผลแบบเงียบ (silent)
    → เก็บผลลัพธ์ไว้ใน queue
    → เพิ่ม pending_m301_count
```

---

## 3️⃣ **ขั้นตอนการตรวจจับขวด (Bottle Detection)**

### 3.1 YOLO Detection
- ใช้โมเดล YOLO ตรวจจับวัตถุในภาพจากกล้อง USB
- Labels ที่ตรวจจับได้: `angle1`, `angle2`, `angle3`, `type`

### 3.2 ตรวจสอบ Angle3 ก่อน (Priority)
```
IF 'angle3' in detected_labels:
  → bottle_type = "M130"
  → combined_ocr_text = "angle3 detected by YOLO"
  → ข้าม OCR
  → ไปที่ handle_bottle_type_detection()
```

### 3.3 OCR Processing (ถ้าไม่ใช่ angle3)
- ครอปส่วน "type" region จากภาพ
- ทำ OCR บน type crops
- ตรวจสอบคำสำคัญ:
  - `"เดิม"` → `bottle_type = "M100"`
  - `"2%"` → `bottle_type = "M110"`
  - `"ลัก"` → `bottle_type = "M120"`

---

## 4️⃣ **ขั้นตอนการจัดการผลลัพธ์ขวด**

### กรณี M130 (Angle3)
```
IF bottle_type == "M130":
  → ตรวจสอบ OCR:
      IF OCR อ่านได้:
        → D7009 = 40
      ELSE:
        → D7009 = 50
  
  → ON M850 (angle3 signal)
  → ON M600
  → เริ่มอ่าน M402 (แทน D6006)
  → ข้ามการตรวจฝา
```

### เขียน Coils:
- **M850** (Coil 850, Unit 1) - Angle3 signal
- **M600** (Coil 600, Unit 1) - Processing complete signal

### เขียน Registers:
- **D7009** (Register 7009, Unit 1) - ผลการตรวจสอบ
  - `40` = M130 + OCR อ่านได้
  - `50` = M130 + OCR อ่านไม่ได้

### อ่าน Coils:
- **M402** (Coil 402, Unit 1) - ใช้แทน D6006
  - อ่านเมื่อ `d6006_monitoring = True` หรือ `angle3_retry_mode = True`

---

### กรณี M100/M110/M120 (ไม่ใช่ angle3)
```
IF bottle_type in ["M100", "M110", "M120"]:
  → เก็บ bottle_type ไว้
  → แสดงสถานะ "รอผลลัพธ์ฝาก่อน ON Modbus..."
  → เริ่มประมวลผลฝา (Cap Detection)
  → รอผลลัพธ์ฝาก่อนส่งสัญญาณ Modbus
```

---

## 5️⃣ **ขั้นตอนการตรวจจับฝา (Cap Detection)**

### ใช้ภาพจาก:
- กล้อง Sentech (`current_sentech_image`)

### หลังจากตรวจฝาเสร็จ:
```
IF ฝาผ่าน (validate_cap_result() == True):
  → ตรวจสอบ bottle_type:
      IF M100: D7009 = 10
      IF M110: D7009 = 20
      IF M120: D7009 = 30
  
  → ON M600
  → อัปเดต UI

ELSE (ฝาไม่ผ่าน):
  → D7009 = 50
  → ON M140 (ฝาไม่ผ่าน signal)
  → อัปเดต UI
```

### เขียน Coils:
- **M600** (Coil 600, Unit 1) - Processing complete
- **M140** (Coil 140, Unit 1) - Cap failed signal

### เขียน Registers:
- **D7009** (Register 7009, Unit 1) - ผลการตรวจสอบ
  - `10` = M100 (เดิม) + ฝาผ่าน
  - `20` = M110 (2%) + ฝาผ่าน
  - `30` = M120 (ลัก) + ฝาผ่าน
  - `50` = ฝาไม่ผ่าน

---

## 6️⃣ **ขั้นตอน Reset (เมื่อ M401 ON)**

### อ่าน Coils:
- **M401** (Coil 401, Unit 1) - Reset signal
  - อ่านเมื่อ `m600_reset_pending = True`

### เมื่อ M401 = ON:
```
→ RESET M600 = 0
→ RESET D7009 = 0
→ RESET M100, M110, M120, M130 = 0
→ RESET M140 = 0
→ RESET M720, M721, M722 = 0 (โหมดรสชาติ)
→ RESET M730-M735 = 0 (2-taste combinations)
→ RESET M740-M742 = 0 (1-taste signals)
→ m600_reset_pending = False
```

### เขียน Coils:
- **M600** = 0
- **M100** = 0
- **M110** = 0
- **M120** = 0
- **M130** = 0
- **M140** = 0
- **M720, M721, M722** = 0
- **M730-M735** = 0
- **M740-M742** = 0

### เขียน Registers:
- **D7009** = 0

### หลังจาก Reset:
```
IF capture_only_mode:
  IF มีคิว (pending_m301_count > 0):
    → ถ่ายภาพจากคิว
    → ON M600 ต่อทันที
    → pending_m301_count -= 1
  ELSE:
    → ON M600 ต่อ (รอ M301 ถัดไป)

ELSE (auto mode):
  IF มีผลลัพธ์ใน queue:
    → แสดงผลลัพธ์จาก queue
    → pending_m301_count -= 1
  ELSE IF มีคิว:
    → ถ่ายภาพจากคิว
    → pending_m301_count -= 1
  ELSE:
    → พร้อมรับ M301 ใหม่
```

---

## 7️⃣ **โหมดถ่ายภาพซ้ำสำหรับ Angle3 (Angle3 Retry Mode)**

### เมื่อ M402 ON (แทน D6006 = 300)
```
→ RESET M130 = 0
→ RESET M850 = 0
→ RESET M600 = 0
→ d6006_monitoring = False
→ m600_reset_pending = False
→ angle3_retry_mode = True
→ angle3_retry_count = 0
→ Reset การประมวลผล
→ ถ่ายภาพ USB ใหม่ทันที (เหมือน M301)
```

### ในโหมดถ่ายภาพซ้ำ:
```
IF ตรวจจับได้ bottle_type != "M130":
  → ส่งสัญญาณตาม bottle_type (D7009 = 10/20/30)
  → ON M600
  → angle3_retry_mode = False

ELSE (ยังเป็น M130):
  → ตรวจสอบ OCR:
      IF OCR อ่านได้: D7009 = 40
      ELSE: D7009 = 50
  → ON M850, M600
  → ถ่ายภาพ USB ใหม่ทันที (ถ่ายซ้ำ)
  → angle3_retry_count += 1
```

### เมื่อ M402 OFF (แทน D6006 = 0)
```
→ RESET M850 = 0
→ angle3_retry_mode = False
→ angle3_retry_count = 0
```

## 8️⃣ **การอ่าน Registers/Coils อื่นๆ**

### อ่านตลอดในโหมด Auto:

#### D6007 (Register 6007, Unit 2) - ประเภทขวด
- อ่านตลอดเมื่อ `program_enabled = True` และ `not capture_only_mode`
- ใช้ตรวจสอบประเภทขวด
- ส่งค่าไปยัง GUI เมื่อค่าเปลี่ยน

#### M403, M404, M405, M406 (Coils 403-406, Unit 1) - ประเภทขวด (แทน D6007)
- อ่านตลอดในโหมด auto
- **M403** = น้ำเต้าหู้รสดั้งเดิม (แทน D6007=100)
- **M404** = น้ำตาลน้อย 2% (แทน D6007=200)
- **M405** = ผสมเม็ดแมงลัก (แทน D6007=300)
- **M406** = NG เต็ม (แทน D6007=400)
- ส่งค่าไปยัง GUI เมื่อค่าเปลี่ยน

#### D5002 (Register 5002, Unit 2) - สถานะระบบ
- อ่านตลอด
- `0` = Close
- `1` = Running
- `2` = Break Point
- `3` = Pause
- `4` = Pre-run
- ส่งค่าไปยัง GUI เมื่อค่าเปลี่ยน

#### D5001 (Register 5001, Unit 2) - Error Code
- อ่านตลอด
- แสดง error code ของระบบ
- ส่งค่าไปยัง GUI เมื่อค่าเปลี่ยน

## 9️⃣ **Coils/Registers ที่ใช้ในโหมด Capture Only (ID 5)**

### อ่าน:
- **M401** (Coil 401, Unit 1) - อ่านตลอดเพื่อแสดงสถานะ

### การทำงาน:
```
IF M301 ON:
  IF M600 พร้อม:
    → ถ่ายภาพทันที
    → ON M600
  ELSE:
    → เพิ่มคิว (pending_m301_count += 1)

IF M401 ON:
  → RESET M600 = 0
  → RESET D7009 = 0
  → IF มีคิว:
      → ถ่ายภาพจากคิว
      → ON M600 ต่อ
      → pending_m301_count -= 1
```

## 🎯 จุดสำคัญ

1. **M301** = สัญญาณถ่ายภาพ (อ่านตลอด)
