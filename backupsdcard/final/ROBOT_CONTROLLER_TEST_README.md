# 🤖 Robot Controller Tester

ไฟล์สำหรับทดสอบการเชื่อมต่อและส่งค่าไปที่ Robot Controller

## 📋 ข้อมูลการเชื่อมต่อ

- **IP Address**: 192.168.1.162
- **Port**: 502 (Modbus TCP)
- **Address**: 0x3101 (12545 ในฐาน 10)
- **Unit ID**: 1 (Slave ID)

## 📁 ไฟล์ที่สร้าง

### 1. `test_robot_simple.py` - แบบง่าย (แนะนำ)
ไฟล์ทดสอบแบบง่าย รันผ่าน command line

**การใช้งาน:**
```bash
# ทดสอบด้วยค่า default (100)
python test_robot_simple.py

# ทดสอบด้วยค่าที่ระบุ
python test_robot_simple.py 100
python test_robot_simple.py 0
python test_robot_simple.py 500
```

**คุณสมบัติ:**
- ✅ เชื่อมต่อกับ robot controller
- ✅ เขียนค่าไปที่ address 0x3101
- ✅ อ่านค่ากลับมาเพื่อยืนยัน
- ✅ แสดงผลลัพธ์แบบละเอียด

### 2. `test_robot_controller.py` - แบบเต็มรูปแบบ
ไฟล์ทดสอบแบบเต็มรูปแบบ มีเมนูให้เลือก

**การใช้งาน:**
```bash
python test_robot_controller.py
```

**เมนู:**
1. เขียนค่าไปที่ register
2. อ่านค่าจาก register
3. ทดสอบเขียนและอ่าน (test value = 100)
4. ทดสอบเขียนและอ่าน (ระบุค่าเอง)
5. ทดสอบหลายค่า (0, 100, 500, 1000)
0. ออกจากโปรแกรม

**คุณสมบัติ:**
- ✅ เชื่อมต่อกับ robot controller
- ✅ เขียนค่าไปที่ register
- ✅ อ่านค่าจาก register
- ✅ ทดสอบหลายค่า
- ✅ เมนูแบบ interactive

แก้ไขในไฟล์:

### เปลี่ยน Port
แก้ไขในไฟล์:
```python
PORT = 502  # เปลี่ยนเป็น port ที่ต้องการ
```

### เปลี่ยน Unit ID (Slave ID)
แก้ไขในไฟล์:
```python
UNIT_ID = 1  # เปลี่ยนเป็น Unit ID ที่ต้องการ
```

## ⚠️ ข้อควรระวัง

1. **ตรวจสอบ Network Connection**
   - ตรวจสอบว่าเครื่องสามารถ ping ไปที่ 192.168.1.162 ได้
   - ตรวจสอบว่า port 502 เปิดอยู่

2. **ตรวจสอบ Robot Controller**
   - ตรวจสอบว่า robot controller เปิดอยู่
   - ตรวจสอบว่า Modbus TCP server ทำงานอยู่

3. **ตรวจสอบ Address**
   - ตรวจสอบว่า address 0x3101 ถูกต้อง
   - ตรวจสอบว่า Unit ID ถูกต้อง

4. **ค่าที่ส่ง**
   - ค่าต้องอยู่ระหว่าง 0-65535 (16-bit unsigned integer)

## 🐛 แก้ไขปัญหา

### ไม่สามารถเชื่อมต่อได้
```
❌ ไม่สามารถเชื่อมต่อได้: 192.168.1.162:502
```

**วิธีแก้:**
1. ตรวจสอบ IP address ถูกต้องหรือไม่
2. ตรวจสอบว่า robot controller เปิดอยู่
3. ตรวจสอบ network connection
4. ตรวจสอบ firewall settings

### ไม่สามารถเขียนค่าได้
```
❌ ไม่สามารถเขียนค่าได้: ...
```

**วิธีแก้:**
1. ตรวจสอบ address ถูกต้องหรือไม่ (0x3101)
2. ตรวจสอบ Unit ID ถูกต้องหรือไม่
3. ตรวจสอบว่า register นั้นเขียนได้หรือไม่ (บาง register อาจเป็น read-only)

### ค่าที่อ่านได้ไม่ตรง
```
⚠️ ค่าที่อ่านได้ไม่ตรง: เขียน 100 แต่อ่านได้ 0
```

**วิธีแก้:**
1. ตรวจสอบว่า address ถูกต้อง
2. ตรวจสอบว่า robot controller รับค่าแล้วหรือไม่
3. อาจต้องรอสักครู่ก่อนอ่านค่า
