# Modbus Simulator - จำลอง PLC สั่งการโปรแกรม Main

โปรแกรมแยกสำหรับ**จำลอง Modbus (PLC)** ให้ส่งสัญญาณไปยังโปรแกรม main (ระบบตรวจจับขวดและ OCR) แทนการต่อกับ PLC จริง

## วิธีใช้

1. **รัน Simulator ก่อน**
   - จากโฟลเดอร์ `final`:
     ```bash
     python tools/modbus_simulator.py
     ```
   - หรือจาก `final/tools`:
     ```bash
     python modbus_simulator.py
     ```
   - กด **เริ่มเซิร์ฟเวอร์** (ค่าเริ่มต้น: Host `0.0.0.0`, Port `5502`)

2. **ตั้งค่าโปรแกรม Main ให้ชี้มา Simulator**
   - แก้ไฟล์ `final/config/settings.py`:
     ```python
     MODBUS_IP = "127.0.0.1"   # ถ้ารัน simulator บนเครื่องเดียวกัน
     MODBUS_PORT = 5502        # ใช้ 5502 เพื่อไม่ต้องรัน as admin (port 502 ต้องสิทธิ์)
     ```
   - ถ้า simulator รันบนเครื่องอื่น ให้ใช้ IP ของเครื่องนั้น และเปิด firewall port 5502

3. **รันโปรแกรม Main** ตามปกติ (จะเชื่อมต่อกับ simulator แทน PLC)

4. **ส่งสัญญาณจาก Simulator**
   - **M301 ถ่าย** = กดเพื่อส่งสัญญาณถ่ายภาพ (pulse ON แล้ว OFF อัตโนมัติ) — ใช้แทนปุ่มถ่ายจริง
   - **M511 เริ่ม** / **M513 หยุด** = เปิด/ปิดการทำงานโปรแกรม
   - **M401** = สัญญาณ M401 ON (reset M600 / แสดงผลรอบ)
   - **M402** = สัญญาณ M402 (ถ่ายซ้ำ angle3)
   - **M403–M406** = เลือกประเภทขวด (กดเลือกหนึ่งในสี่)
   - **D5500** = โหมด: 5=Capture only, 7=Auto, 8=ID 8 reset modbus แล้วกด "ตั้ง D5500"
   - **M700 / M701** = เริ่มระบบ / หยุดระบบ

## สัญญาณที่จำเป็น (สรุป)

| สัญญาณ   | ความหมาย / ใช้เมื่อไหร่ |
|----------|---------------------------|
| M301     | สัญญาณถ่ายภาพ (ปุ่มกดแทนถ่าย) — ส่งเป็น pulse |
| M511     | เริ่มโปรแกรม (รับ M301 ได้) |
| M513     | หยุดโปรแกรม |
| M401     | แจ้งรอบเสร็จ / reset M600, แสดงผล |
| M402     | ถ่ายซ้ำ angle3 / reset M130, M850, M600 |
| M403–M406| ประเภทขวด (ดั้งเดิม, น้ำตาล 2%, ผสมแมงลัก, อื่น) |
| M512     | พร้อมรับ M513 (ออกจากโปรแกรม) |
| D5500    | โหมด: 5=ถ่ายอย่างเดียว, 7=Auto, 8=Reset modbus |
| M700/M701| เริ่ม/หยุดระบบ |

## หมายเหตุ

- Port **5502** ใช้เพื่อไม่ต้องรันคำสั่ง as Administrator (บน Windows, port 502 มักต้องสิทธิ์)
- ถ้าต้องการใช้ port 502 จริง ให้แก้ Port ใน simulator เป็น 502 และรันโปรแกรมที่เปิดด้วยสิทธิ์ Administrator
- แผง "Register ที่ main ส่งกลับ" แสดงค่า D7009, D5500 ที่โปรแกรม main เขียนกลับมา (อ่านอย่างเดียว)
